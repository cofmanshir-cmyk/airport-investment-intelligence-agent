# Airport Investment Intelligence Agent

Ask airport investment questions in plain English. A real LLM chooses a deterministic Python
tool, the tool calculates the result on public BTS and FAA data, and the LLM explains it.

This is a working demo. **The Airport Opportunity Score is not implemented**, and results are
screening indicators, not investment advice or return forecasts.

## Try it

In a Codespaces terminal, from the project folder:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m src.cli
```

You need an API key from the [Anthropic Console](https://console.anthropic.com/). The app asks
for it with hidden input and keeps it in memory only. To avoid typing it each time, set
`ANTHROPIC_API_KEY` as a [Codespaces secret](https://docs.github.com/en/codespaces/managing-your-codespace/managing-your-account-specific-secrets-for-github-codespaces).
Never put a key in a repository file.

Each question calls the paid API, using `claude-opus-5-5` by default. Set `ANTHROPIC_MODEL` to
use another model.

### Use Gemini instead

```bash
.venv/bin/python -m src.cli --provider gemini
```

The app asks for your Gemini API key the same way, confirms which Flash model the key can use,
and then uses the same tools and safeguards. To protect a limited allowance, retries are off, each
answer shows the calls used, and a session stops at 6 Gemini calls. A question usually takes 2
calls. Set `GEMINI_MAX_CALLS` or `GEMINI_MODEL` to change the limit or the model. The counter
covers one session only, so it can't track your total allowance.

### Use the web interface

```bash
.venv/bin/streamlit run app.py
```

In Codespaces, open the **Ports** tab, then open port 8501 in your browser. Keep the port's
visibility **Private**. The page uses Gemini; enter your key in the sidebar. It stays in memory
for that browser session and is never saved. Example buttons only fill in the question box, and
nothing is sent until you select **Ask**.

## Example questions

- Which airports have the fastest 3-year passenger growth?
- Rank New England airports by 10-year passenger growth.
- Compare LAX and SNA congestion.
- Give me a profile of SFO.
- What percentage of flights departing ANC are long-haul?

Follow-ups work, such as "what about at 2,400 miles?". Type `/raw` to see the last tool results
as JSON, or `/quit` to exit.

## How it works

| Layer | File | Role |
|---|---|---|
| Interface | `src/cli.py` | Chat, plus an evidence section generated by code |
| LLM loop | `src/agent.py` | The LLM selects tools and explains; unmatched numbers are flagged |
| Tools | `src/tools.py` | Validate inputs and attach definitions, sources and caveats |
| Calculations | `src/analytics.py` | Deterministic Python, with no LLM calls |
| Data | `src/pipeline.py` | Fetches, validates and snapshots public data |

The number check flags figures to review. It can't prove an explanation is right, so compare
important results with `/raw`.

## Provisional and unavailable

- **Flight metrics include freighters.** The agreed passenger-only definition needs historical
  T-100 All Carriers route data, which isn't loaded yet.
- **Eligibility:** the 100,000 enplanement threshold is provisional.
- **Incomplete years:** shown as null under a strict 12-month rule. This decision is open.
- **Service class:** class F versus F+L is open, and passenger totals include all classes.
- **Not measured:** terminal capacity, unmet demand and profitability.

See [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md) for sources and limitations.

## Tests

```bash
.venv/bin/python -m pytest
```

Tests use a scripted stand-in for the LLM, so they need no API key.

To rebuild the data, put the route file in `data/raw/` and run `.venv/bin/python -m src.pipeline`.
